# 大海原を操れ！魔法の操舵輪

カメラに手をかざして傾けると、画面の操舵輪が回り、船の進路が変わります。
正面から迫ってくる岩を、舵を切ってよけるゲームです。
**両手でも片手でも操作でき**、難易度は3段階から選べます。

**インストール不要・ブラウザだけで動く**ように作ってあるので、Windowsのパソコンであれば
どれでも同じように使えます(Chrome または Edge が必要です)。

## 1. 遊び方

1. ブラウザ(Chrome または Edge)で公開URLを開く。
2. 画面上部の **「カメラ開始」** を押す。
3. ブラウザが「カメラの使用を許可しますか?」と聞いてくるので、**「許可」を押す**
   (ブラウザのセキュリティ機能のため、必ず毎回あなた自身がクリックする必要があります)。
4. カメラに手をかざす。左下の小窓に金色の線で手が表示されていればOK。
   **両手でも片手でも操作できます**(手の数を見て自動で切り替わります)。
   - **両手**… 舵輪を握るように両手を前に出し、両手を傾けて回す。
     画面の操舵輪にも手が現れて、一緒に輪を握ります。
   - **片手**… 手をまっすぐ立てて、左右に傾ける。
5. その姿勢のまま **「今の手の向きを基準(0°)にする」** を押す(キャリブレーション)。
   - 両手用と片手用で基準は**別々に記録**されます。両方使うなら、それぞれの構えで一度ずつ押してください。
6. **難易度**(やさしい / ふつう / むずかしい)を選ぶ。
7. **「ゲーム開始」** を押す。
8. 舵を切って、正面から迫る岩をよける。
   - **船はすぐには曲がりません。** 岩が来る前に早めに舵を切ってください。
   - 船体をすべて失うと終了です。航行距離と避けた岩の数が記録されます。
   - 自己最高記録は**難易度ごとに**このパソコン内へ自動保存されます。

### 難易度

| 難易度 | 船体 | 速さ | 岩の間隔 | 航路の広さ |
| --- | --- | --- | --- | --- |
| やさしい | 5 | 遅い(10→26) | 広め | 広い |
| ふつう | 3 | 標準(13→40) | 標準 | 標準 |
| むずかしい | 2 | 速い(17→52) | 詰まっている | 狭い |

### 操作が思ったとおりでないとき

- 動きが自分の感覚と**逆**に感じる → 右下の「設定」を開き、「左右反転」のチェックを外す。
- 反応が**敏感すぎる / 鈍すぎる** → 「感度」のスライダーを調整する。
- 舵の**効く範囲**を変えたい → 「最大舵角」のスライダーを調整する。
- 設定はこのパソコン内に自動保存されます。

### カメラが使えないとき

キーボードの **← → キー** でも舵を操作できます(動作確認用・予備)。

### 音について

波と風の音が常に流れ、船が速くなるほど低いうなりが加わります。
汽笛(出航)、衝突、岩をよけたときの風切り音、基準合わせのチャイムなどの効果音があります。

- 画面上部の **「♪ 音 ON / 音 OFF」** ボタンで切り替えられます(設定は保存されます)。
- ブラウザの決まりで、**最初にどこかをクリックするまで音は鳴りません**。これは不具合ではありません。
- 別のタブに切り替えている間は自動で音が止まります。

## 3. ローカルで試す場合(公開URLを使わない場合)

開発中の確認用です。**注意: `index.html` をダブルクリックして直接開く(`file://`)方法は

### 方法A: 付属のバッチファイルを使う(Windows・Pythonが入っている場合)

1. このフォルダの中にある `start-local-server.bat` をダブルクリックする。
2. 黒い画面(コマンドプロンプト)が開き、サーバーが起動する。
3. ブラウザで `http://localhost:8000` を開く。
4. 使い終わったら、その黒い画面を閉じるとサーバーが止まります。

Pythonが入っていない場合はエラーメッセージが出ます。その場合は方法Bか、公開URLを使ってください。

### 方法B: Claude Code Desktop に頼んでセットアップしてもらう

このプロジェクトには `CLAUDE.md` というファイルが入っており、Claude Code はフォルダを開くと
自動的にこの内容を読み込みます。

1. Claude Code Desktop アプリを開き、このプロジェクトのフォルダを開く。
2. チャット欄に次のように入力する:
   > `README.mdとCLAUDE.mdを読んで、このプロジェクトをローカルで動作確認できるようにセットアップして`
3. Claude Codeがサーバーを起動し、開くURL(例: `http://localhost:8000`)を教えてくれます。
4. **そのURLをブラウザで開く操作と、カメラ許可のクリックはあなた自身が行う必要があります。**

## 4. 調整のしかた(むずかしさ・操作感を変えたいとき)

数値を書き換えるだけで調整できるように、設定はファイルの先頭にまとめてあります。

### 各難易度のむずかしさ → `game.js` の `DIFFICULTY_PRESETS`

`easy` / `normal` / `hard` の3つがあり、それぞれ次の値を持っています。
ここを書き換えれば、その難易度だけを調整できます。

| 項目 | 意味 | 大きくすると |
| --- | --- | --- |
| `startSpeed` | 開始時の速さ(m/秒) | 最初から速くなる |
| `speedGain` | 1秒ごとに速くなる量 | だんだん急に難しくなる |
| `maxSpeed` | 速さの上限 | 終盤がより速くなる |
| `spawnInterval` | 岩が出る間隔(秒) | 岩がまばらになる(やさしい) |
| `spawnIntervalMin` | 最も難しくなったときの間隔 | 終盤がやさしくなる |
| `hardenTime` | 最高難易度に達するまでの秒数 | ゆっくり難しくなる |
| `laneHalfWidth` | 航路の広さ(片側何メートルか) | よけやすくなる |
| `headingLag` | 舵への反応の速さ | 軽快に曲がる(小さいと重い船) |
| `maxHp` | 船体の数(何回ぶつかったら終わりか) | 長く遊べる |
| `label` | 画面に出す難易度の名前 | — |

**まず調整するなら `spawnInterval`(岩の間隔)と `startSpeed`(速さ)の2つ**が効果的です。

難易度を増やしたい場合は `DIFFICULTY_PRESETS` に項目を足し、`index.html` の難易度ボタンに
`data-difficulty="キー名"` のボタンを1つ追加するだけで動きます。

### 難易度によらない共通設定 → `game.js` の `GAME_CONFIG`

`focal`(遠近の強さ)、`cameraHeight`(視点の高さ)、`spawnDistance`(岩が現れる距離)、
`maxHeading`(舵いっぱいのときの船の向き)、`hullHalfWidth`(当たり判定の船幅)、
`invincibleTime`(被弾後の無敵時間)。

### 手の検出まわり → `main.js` の `CONFIG`

- `smoothingAlpha`: 動きの滑らかさ。小さくすると滑らかだが反応が遅くなる。
- `wheelTurnRatio`: 舵角に対して操舵輪を何倍回すか。
  **1.0(等倍)にしてあります。** 輪には手の絵が乗っていて、それが実際の自分の手の傾きに
  見えるようにするためです。ここを大きくすると輪は派手に回りますが、手の絵が実際の手とずれます。
- `computeOneHandAngleDeg()` / `computeTwoHandAngleDeg()`: 角度の求め方を変えたい場合はここ。
  片手は「手首(0番)→中指の付け根(9番)」の向き、両手は「左右の中指の付け根を結ぶ線」の傾きを使用。

### 音量 → `sound.js` の `VOLUME`

`master`(全体)、`waves`(波)、`wind`(風)、`droneMax`(全速時の低いうなり)、
`horn`(汽笛)、`crash`(衝突)、`dodge`(よけた音)、`chime`、`blip`(ボタン)を個別に調整できます。
出口にリミッターが入っているので、多少上げても音割れはしません。

### 見た目 → `style.css` の `:root`

`--gold` などの色をまとめてあります。ここを変えると全体の配色が変わります。
海や岩の色は `game.js` の描画関数(`drawSky` / `drawSea` / `drawRocks`)の中にあります。
