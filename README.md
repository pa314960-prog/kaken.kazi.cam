# カメラの手ジェスチャーで舵(rudder)を動かす

カメラに手をかざして左右に傾けると、画面上の舵(ラダー)がその角度に合わせて動きます。
**インストール不要・ブラウザだけで動く**ように作ってあるので、Windowsのパソコンであれば
どれでも同じように使えます(Chrome または Edge が必要です)。

## 公開URL

https://pa314960-prog.github.io/kaken.kazi.cam/

## 0. 全体像(まず結論)

- このプロジェクトは **ただのWebページ**(HTML/CSS/JavaScriptのみ)です。
- 手の検出には Google の MediaPipe Hands を使っていますが、これはページを開いたときに
  インターネット経由で自動的に読み込まれるので、**あなたが何かをインストールする必要はありません**。
- 「他のパソコンでも動かしたい」という点は、**GitHub Pagesでこのページを公開してURLで開く**
  方法が一番簡単です。公開さえしてしまえば、あとはどのPCでもそのURLをブラウザで開くだけです。
- ただし、以下の2つだけは **あなたがブラウザやGitHubの画面上で手動で操作する必要があります**
  (コードだけでは自動化できない部分です)。
  1. GitHub Pagesを有効にする(GitHubの設定画面)
  2. ページを開いたときにブラウザが出す「カメラを許可しますか?」に「許可」を押す

## 1. GitHub Pagesで公開する(すべてのPCで使えるようにする方法・おすすめ)

これをやっておくと、以後は他のパソコンでもインストール一切不要で、URLを開くだけで使えます。

1. GitHubでこのリポジトリ(`kaken.kazi.cam`)のページを開く。
2. 上部メニューの **Settings**(設定)をクリックする。
3. 左側メニューの **Pages** をクリックする。
4. 「Build and deployment」の「Branch」で、コードが入っているブランチ(例: `main` または
   このプロジェクトを作業したブランチをマージした後のブランチ)と `/ (root)` を選んで
   **Save** を押す。
5. 少し待つと(1〜2分)、ページ上部に公開されたURLが表示される。
   - 通常は `https://<あなたのGitHubユーザー名>.github.io/kaken.kazi.cam/` の形になります。
   - リポジトリには `CNAME` という設定ファイルを入れておいたので、もし
     `kaken.kazi.cam` という独自ドメインをすでに持っていてDNS設定もできる場合は、
     そのドメインでも表示されるようになります(下記6.参照。持っていない場合はこの手順は不要です)。
6. **(独自ドメインを使いたい場合のみ)** ドメインを管理しているサービス(お名前.comなど)の
   管理画面(UI操作)で、`kaken.kazi.cam` のDNSに GitHub Pages 向けの CNAME レコードを追加する
   必要があります。これは本リポジトリのコードでは行えない、ドメイン側の管理画面での作業です。
   不要であれば、`https://<ユーザー名>.github.io/kaken.kazi.cam/` のURLをそのまま使えば問題ありません。

以後、他のパソコンで使うときは **そのURLをブラウザで開くだけ** です。

## 2. 使い方(ページを開いた後の操作)

1. ブラウザ(Chrome または Edge)で公開したURL(またはローカルサーバーのURL)を開く。
2. 画面の **「カメラ開始」** ボタンを押す。
3. ブラウザ上部に「カメラの使用を許可しますか?」というポップアップが出るので、**「許可」を押す**
   (これはブラウザのセキュリティ機能のため、必ず毎回あなた自身がクリックする必要があります)。
4. カメラに手をかざす。緑色の線で手が認識されていればOK。
5. 手をまっすぐ立てた状態(自分にとって「まっすぐ」と感じる向き)で
   **「今の手の向きを基準(0°)にする」** ボタンを押す(キャリブレーション)。
6. 手を左右に傾けると、右側の舵の絵(赤い板)が連動して回転します。数値は「舵角」として表示されます。
7. 動きが自分の感覚と逆に感じる場合は、「左右反転」のチェックを外してみてください。
8. 反応が敏感すぎる・鈍すぎる場合は「感度」のスライダーを、動く範囲を変えたい場合は
   「最大舵角」のスライダーを調整してください。設定はこのパソコン内に自動保存されます。

## 3. ローカルで試す場合(GitHub Pagesを使わない場合)

開発中の確認や、公開前に試したい場合の方法です。**注意: `index.html` をダブルクリックして
直接開く(`file://`)方法はカメラが使えず動きません。** 必ず簡易サーバー経由で開いてください。

### 方法A: 付属のバッチファイルを使う(Windows・Pythonが入っている場合)

1. このフォルダの中にある `start-local-server.bat` をダブルクリックする。
2. 黒い画面(コマンドプロンプト)が開き、サーバーが起動する。
3. ブラウザで `http://localhost:8000` を開く。
4. 使い終わったら、その黒い画面を閉じるとサーバーが止まります。

Pythonが入っていない場合はエラーメッセージが出ます。その場合は方法Bか、上記の
GitHub Pagesでの公開をおすすめします。

### 方法B: Claude Code Desktop に頼んでセットアップしてもらう

このプロジェクトには `CLAUDE.md` というファイルが入っており、Claude Code はフォルダを開くと
自動的にこの内容を読み込みます。

1. Claude Code Desktop アプリを開く。
2. このプロジェクトのフォルダ(このリポジトリをクローンした場所)を開く。
   - まだパソコンにクローンしていない場合は、Claude Codeのチャットで
     「このリポジトリをクローンしてセットアップして」と頼めば、`git clone` から
     ローカルサーバー起動まで代わりに行ってくれます。
3. チャット欄に次のように入力する:
   > `README.mdとCLAUDE.mdを読んで、このプロジェクトをローカルで動作確認できるようにセットアップして`
4. Claude Codeが `python -m http.server` などでサーバーを起動し、
   開くべきURL(例: `http://localhost:8000`)を教えてくれます。
5. **そのURLをブラウザで開く操作と、カメラ許可のクリックはあなた自身が行う必要があります**
   (Claude Codeが自動でブラウザを操作してカメラ許可を押すことはできません)。

## 5. 改造・調整のしかた(修正しやすいポイント)

すべて `main.js` の中にまとまっています。

- `CONFIG.smoothingAlpha`: 動きの滑らかさ。小さくすると滑らかだが反応が遅くなる。
- `sensitivity`(画面のスライダー、初期値は `main.js` 内 `sensitivityInput.value` の初期値):
  手の傾きに対する舵角の反応の強さ。
- `maxAngle`: 舵が動く最大角度。
- `computeHandAngleDeg()`: どのランドマーク(手のどの点)を使って角度を計算するかを変えたい場合は
  ここを編集する。現在は「手首(0番)→中指の付け根(9番)」の向きを使用。
- 舵の見た目(SVG)は `index.html` の `#rudder-svg` 部分。船や舵の形を変えたい場合はここを編集する。

コードはCDN読み込みのみで、npm/ビルドツールを使っていません。これは
「他のPCでもそのまま動く」という要件を保つための意図的な選択です。ライブラリを追加する場合は、
なるべくCDNの `<script>` 追加で済む形を優先してください。
